Detailed Description

Главный модуль веб-сервера приложения «Планировщик задач».

Реализует HTTP-сервер на основе библиотеки cpp-httplib, обрабатывает REST API для задач, подзадач, аутентификации, а также раздаёт статические файлы (HTML, CSS, JS).
